### 💙 Welcome to Welcome Hub!

Welcome Hub is a modern Windows application designed to make your computer easier and more convenient to use.

It brings together your installed applications, useful Windows tools, computer locations, and personalization options in one convenient interface.

Welcome Hub provides a friendly starting point for exploring and using your computer.

The main starting page of Welcome Hub.

* Access the main Welcome Hub experience.

Discover and launch applications installed on your computer.

### 💻 Installation Guide

Welcome Hub is distributed as a standalone Windows executable.

You do not need to install Python separately.

### Installation steps

* Download `WelcomeHub.exe`.

* Choose a convenient folder on your computer.

* Save the executable in that folder.

* Double-click `WelcomeHub.exe`.

* Welcome Hub will launch.

That's it!

There is no additional setup wizard or separate Python installation required.

Important: Keep the executable in a permanent folder so your shortcuts continue working.

### 🚀 How to Make Welcome Hub Start Automatically with Windows

You can configure Windows to launch Welcome Hub automatically whenever you sign in.

Welcome Hub uses Microsoft's built-in Windows Startup folder.

No additional software or custom startup configuration is required.

### Step 1: Locate WelcomeHub.exe

Find the folder where you saved `WelcomeHub.exe`.

### Step 2: Create a shortcut

* Right-click `WelcomeHub.exe`.

* Select Create shortcut.

* Windows will create a shortcut to the application.

* Copy the shortcut.

A shortcut is a small file that points to the original executable. It is normal for it to be much smaller than the actual application.

### Step 3: Open the Windows Startup folder

* Press `Win + R`.

* Type:

`shell:startup`

3\. Press Enter.

Windows will open your personal Startup folder.

### Step 4: Add the shortcut

Paste the Welcome Hub shortcut into the Startup folder.

Congratulations!

Welcome Hub should now launch automatically whenever you sign in to Windows.

### How to disable automatic startup

If you no longer want Welcome Hub to launch automatically:

* Press `Win + R`.

* Type `shell:startup`.

* Press Enter.

* Find the Welcome Hub shortcut.

* Delete the shortcut.

This only disables automatic startup. It does not uninstall Welcome Hub or delete the executable.

### ❓ Troubleshooting

### Welcome Hub does not open

* Check that the download completed successfully.

* Try opening the EXE again.

* Download a fresh copy from the official GitHub Release if necessary.

### Welcome Hub does not start with Windows

* Open the Startup folder using `shell:startup`.

* Check that the Welcome Hub shortcut exists.

* Make sure the shortcut points to the correct EXE.

* Check Windows startup application settings.

### An application is missing from App Library

Welcome Hub displays applications it can discover on your Windows installation. Make sure the application is installed and available to Windows.

### My Welcome Hub shortcut stopped working

The executable may have been moved or renamed.

Create a new shortcut from the current location of `WelcomeHub.exe`.

### How do I remove Welcome Hub from Windows Startup?

Delete its shortcut from the Startup folder. You can still open Welcome Hub manually whenever you want.
